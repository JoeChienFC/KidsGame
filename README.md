# 公主獨角獸與 Poli 救援隊 🦄🚓

一起在同一台電腦上合作玩的 Windows 桌面遊戲。

---

## 🎮 玩法

這是一款**雙人合作**遊戲，兩個小朋友共用一個鍵盤。**沒有失敗、沒有計時、沒有 Game Over**——任何按鍵都會有正向回饋。

### 角色分工

| 玩家 | 控制 | 按鍵 |
|---|---|---|
| 👧 **姐姐**（4 歲） | 騎獨角獸的公主 | **方向鍵** ↑ ↓ ← → |
| 👦 **弟弟**（2 歲） | Poli 救援車（自動跟隨姐姐） | **空白鍵** |

### 怎麼玩

1. **姐姐探索地圖**：用方向鍵帶獨角獸公主在彩虹草原上走動，找彩虹水晶 💎、找需要救援的小動物。
2. **Poli 自動跟著姐姐**：弟弟不用控制方向，Poli 會像小跟班一樣跟在獨角獸後面。
3. **弟弟負責救援**：當姐姐走到「救援事件」（小貓被樹幹壓住、氣球卡在樹上、小狗被水坑擋住）旁邊時，弟弟狂按空白鍵 → Poli 就會一直推進救援進度。
4. **進度條滿了** → 救援成功！🎉 畫面會閃白光、震動、慢動作 0.4 秒、爆出大量愛心和煙火，飄出「救到了!」字樣。
5. **撿水晶**：獨角獸走過水晶會自動撿起，畫面顯示 `+1`。
6. **三件救援都完成** → 進入慶祝畫面 🎊：小貓、小狗、小兔子在彩虹下跳舞 5 秒。

### 弟弟亂按空白鍵會怎樣？

**永遠有反應**。不在救援事件旁邊按空白鍵，Poli 會：
- 鳴笛 + 紅藍頂燈閃爍
- 車身彈跳
- 周圍噴出小煙火粒子

設計就是**讓 2 歲狂按也好玩**，亂按 = 角色一直反應 = 弟弟永遠開心。

## 📥 安裝（首次）

### 1. 安裝 .NET 8 SDK
從 https://dotnet.microsoft.com/download/dotnet/8.0 下載並安裝（選 SDK 版本）。

### 2. clone 這個 repo
```powershell
git clone https://github.com/JoeChienFC/KidsGame.git
cd KidsGame
```

### 3. 跑起來
```powershell
dotnet run
```

第一次會自動下載 Raylib-cs 套件，需要一兩分鐘。之後就秒開。

## 🎨 素材

### 遊戲實際使用
`assets/` 資料夾內的圖片、音效、字型——**已包含**在 repo，clone 完即可直接玩。

### 素材原始檔（給之後想換素材時參考）
也一併推上 repo 以便換電腦使用：
- `kenney_*/` — Kenney.nl 下載的原始素材包（CC0 授權）
- `Noto_Sans_TC/` — Google Noto 繁中字型完整包
- `poli.png`、`公主.png`、`獨角獸.png` — 角色原始圖

### 缺素材時
程式有 fallback：若任一檔案找不到，會用程式繪製的色塊代替，**不會崩潰**。

## 🛠️ 開發

### 專案結構
```
KidsGame/
├── Program.cs / Game.cs    # 進入點、主迴圈
├── Scenes/                 # 標題、遊戲、慶祝畫面
├── Entities/               # Unicorn / Poli / Crystal / RescueEvent
├── Effects/                # 粒子系統、浮動文字
├── Audio/                  # 音效管理（防疊加）
├── AssetLoading/           # 資源載入（含缺檔 fallback）
├── Util/                   # 數學小工具
└── assets/                 # 遊戲用素材
```

### 規劃文件
- [`DEVELOPMENT_PLAN.md`](DEVELOPMENT_PLAN.md) — 完整開發計畫書（給 AI 看的規格）
- [`ASSETS.md`](ASSETS.md) — 素材取得與替換指引

### 技術棧
- C# / .NET 8
- [Raylib-cs](https://github.com/raylib-cs/raylib-cs) 7.0.2
- 解析度 1280×720 / 60 FPS

## 📝 設計鐵律

1. **永不失敗** — 沒有計時、沒有死亡、沒有 Game Over
2. **永遠有回饋** — 任何按鍵都會發出聲音 + 視覺反應
3. **2 歲容錯** — 狂按空白鍵不會讓畫面爆掉（粒子上限、音效防疊加）
4. **無敵路徑** — 撞到障礙物會在邊緣滑開，絕不卡死
